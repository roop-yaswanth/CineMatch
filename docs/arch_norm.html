CineMatch Implementation Guide

A cross-cultural recommendation pipeline optimized for long-tail international discovery. This architecture utilizes contrastive graph learning (XSimGCL) paired with instruction-aware LLM embeddings (Qwen3), finalized by Determinantal Point Processes (DPP) for rigorous set-level diversity.

1. Semantic Pipeline

QWEN3-4B EMBEDDING

Based on empirical MTEB Multilingual benchmarks, Qwen3-4B outperforms BGE-M3 (69.5 vs 59.56). Both are contrastively trained for retrieval, but Qwen3's larger parameter space yields superior zero-shot cross-lingual alignment.

Instruction & Query Assembly

To unlock maximum zero-shot retrieval performance, the query vector must be explicitly constructed using a chronologically decayed concatenation of recent interactions, prepended with a task instruction.

# 1. Assemble top 5 recent likes with metadata
recent_items = [f"'{m.title}' ({m.genres})" for m in top_5_likes]
user_history_text = ", ".join(recent_items)

# 2. Online Query Generation
prompt = "Instruct: Given a movie description, retrieve semantically similar movies.\nQuery: " + user_history_text
u_qvec = qwen3.encode(prompt)

Why this matters: Concatenating titles and core genres captures temporal drift and localizes the LLM's attention, avoiding the noisy dilution of averaging 50 separate movie embeddings.

FAISS Index Selection

While `IndexIDMap2(HNSW32)` supports incremental IDs and operates faster, we deliberately deploy `IndexIDMap2(FlatIP)` for the MVP phase.

Justification: FlatIP provides a mathematically exact baseline (Recall@K = 1.0) without ANN quantization or graph-building overhead.

2. Collaborative Graph

XSimGCL (2023)

For a cross-cultural system where foreign films live in the long-tail of the dataset, XSimGCL is the SOTA choice over UltraGCN/LightGCN.

Cross-batch Simulated Graph Contrastive Learning

Standard models push popular English blockbusters to all users due to inherent popularity bias. XSimGCL utilizes noise-based contrastive learning in a single pass to produce much more uniform embedding distributions. This mathematically protects and surfaces long-tail items (Telugu, Tamil, Korean films) that would otherwise be buried by the algorithm.

RecBole Integration

XSimGCL is natively supported in RecBole. Requires a single config change: `model = 'XSimGCL'`, yielding statistically significant NDCG improvements on highly sparse interaction graphs.

3. Reranking & Dynamic Fusion

Qwen3-Reranker-4B

Applying an external reranker introduces semantic drift. We explicitly pair the Qwen3-Embedding with the Qwen3-Reranker for coherent score distributions across the pipeline. Ranked 1st on MTEB multilingual reranking benchmarks (June 2025).

3-DIMENSIONAL MLP GATING (SOFTMAX)

A fixed $\gamma$ and an artificially constrained $\alpha = 1 - \beta$ setup severely underfits user complexity. A power user with 500 ratings derives vastly different utility from the Cross-Encoder compared to a new user. The gating mechanism must dynamically allocate weights across all three components.

The Multi-Layer Perceptron

A small network processes user state features and outputs an unnormalized logits vector, which is passed through Softmax to guarantee $\alpha + \beta + \gamma = 1$.

  • Input: [log(Degree), RatingVar, RecencyScore, LangEntropy, CrossLingualRatio]
  • Network: Linear → ReLU → Linear → Softmax
  • Output: $[\alpha(u), \beta(u), \gamma(u)]$

Cross-cultural gating logic: A user with high LangEntropy already watches across cultures — the MLP learns to trust CF more (β↑). A monolingual user gets higher semantic weight (α↑) to discover cross-cultural content via Qwen3 embeddings. This directly drives CCDR@K improvement.

Min-Max Normalization

CRITICAL: XSimGCL dot products and Qwen Cosine distances occupy disparate mathematical spaces. Per-batch min-max normalization ($\tilde{x}$) is strictly enforced before fusion.

Cold-Start Fallback

For users with <5 interactions, the gating bypasses CF entirely (β=0), relying on semantic retrieval as the cold-start fallback. When log(Degree) → −∞, the softmax collapses to α≈1, β≈0, γ≈0 — pure semantic. This behavior is enforced as a hard rule rather than depending on learned weights.

// Fully Dynamic Min-Max Normalized Late Fusion $$ FinalScore(i) = \alpha(u)\widetilde{FAISS}(i) + \beta(u)\widetilde{CF}(i) + \gamma(u)\widetilde{Rerank}(i) $$

4. Set-Level Diversity (DPP)

Determinantal Point Processes (DPP)

Replaces the myopic MMR approach. DPPs evaluate diversity globally in one shot. The probability of selecting a set $S$ is proportional to the determinant of the kernel matrix $L_S$, representing the total "volume spanned" by the embeddings in the semantic space.

// The Quality-Diversity Kernel Matrix L $$ L_{i,j} = q_i \cdot q_j \cdot \text{sim}(\text{Qwen}_i, \text{Qwen}_j) $$
// Where q_i integrates the language boost directly into quality $$ q_i = FinalScore(i)^{1/2} \cdot (1 + \delta_{lang}(i)) $$
// Probability of selecting set S $$ \mathcal{P}(S) \propto \det(L_S) $$

Inference: Greedy MAP inference runs in $O(N \cdot K^2)$ time, requiring $<2\text{ms}$ for $K=30$. Completely separates the language boost signal into the intrinsic item quality parameter $q_i$.

5. Comprehensive Metrics

NDCG@K & MRR

Position-sensitive accuracy and latency to the first relevant item.

CCDR@K

Cross-Cultural Discovery Rate. Percentage of relevant recommendations outside the user's primary history language.

ILD@K (Intra-List Diversity)

Calculates the average pairwise cosine distance within the top-K list. Without ILD, we cannot mathematically prove our DPP implementation actually improves set variance over a relevance-only baseline.

Catalog Coverage@K

Percentage of the 1.3M item catalog that appears in *any* user's Top-K. Validates that the XSimGCL long-tail enhancement actually surfaces niche items globally.
